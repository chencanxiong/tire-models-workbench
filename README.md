# 轮胎型号工作台（tire-models-workbench）

一个部署在 GitHub Pages 上的轮胎型号资料库：每个型号可关联多张照片与视频，支持**多设备访问、查询、下载**；管理员可新增 / 删除（分类、型号、图片、视频）。

## 访问地址
https://chencanxiong.github.io/tire-models-workbench/

## 权限模型
- **普通访客（任何人）**：左侧浏览分类（一级菜单）→ 型号（二级菜单）→ 查看图片/视频，点击「下载」保存到本机。无需登录。
- **管理员**：右上角「管理员登录」→ 输入管理员密码（默认 `123789`，在 `config.js` 的 `ADMIN_PASSWORD` 修改）→ 即显示「＋ 添加分类 / ＋ 添加型号 / ⬆ 上传 / 🗑 删除」等按钮，操作直接同步到 GitHub（无需粘贴 Token）。
  - **推荐（已内置支持）**：把写凭据放到后端代理，见 `proxy/` 目录的 Cloudflare Worker。在 `config.js` 填入 `PROXY_URL` 后，前端完全不持有 Token，最安全。
  - **当前临时方案**：未配置代理时，`config.js` 内仍保留一个分片写入的细粒度 Token 作为回退；代理上线并验证可用后，建议删除该段。
  - 退出管理员：点击「退出管理员」即隐藏增删按钮。

## 删除按钮位置（按你的要求）
1. **一级菜单（分类）**：每个分类行右侧的 🗑 —— 删除整个分类及其下所有型号与媒体。
2. **二级菜单（型号）**：每个型号行右侧的 🗑 —— 删除该型号及其下所有图片/视频。
3. **图片/视频界面**：每张媒体卡片下方的「🗑 删除」—— 删除单个文件。

## 数据存放
- 结构索引：`tires.json`（分类 → 型号 → 媒体列表）
- 媒体文件：`media/<分类ID>/<型号ID>/<文件名>`
- 全部保存在本仓库，通过 GitHub Pages 公开提供，多设备通用。

## 管理员操作指引
1. 打开网页 → 右上角「管理员登录」→ 输入管理员密码 → 登录。
2. 添加分类：右上角「＋ 添加分类」。
3. 添加型号：选中某分类后，面板右上角「＋ 添加型号」。
4. 上传图片/视频：选中某型号后，面板右上角「⬆ 上传图片/视频」（可多选）。
5. 删除：使用上述三层 🗑 按钮，二次确认后生效。

## 注意事项
- **单文件大小限制**：GitHub Contents API 单次上传约 25MB。超过此大小的视频会被跳过，请先压缩，或改用 Git LFS / 对象存储。
- **凭据安全（两层方案）**：
  - **最安全（推荐）**：部署 `proxy/` 里的 Cloudflare Worker 后端代理，在 `config.js` 填入 `PROXY_URL`。Token 只存在代理端（设为 Worker Secret），前端永不直接接触，杜绝源码泄露。详见 `proxy/README.md`。
  - **当前临时回退**：未配置代理时，`config.js` 内保留一个分片写入的**细粒度** Token（`github_pat_...`，仅授权本仓库、Contents: Read and Write）。任何人查看源码都能还原它，但因细粒度且仅限本仓库，泄露影响只限于本仓库。代理上线验证可用后，建议删除该段。
  - 无论哪种方案，`ADMIN_PASSWORD` 只是界面门禁（源码可见），用于避免普通访客误删，**不是真正的鉴权**；不要依赖它防恶意删除。
- **仓库为公开**：任何人都能访问页面与媒体文件（符合"其他人只查看下载"的需求）。若资料需保密，请将仓库改为私有并另行处理 Pages 访问权限。
